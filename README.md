# lsz

极简但实用的终端文件导航器，面向日常开发目录浏览：

- 列出文件并显示持久化备注。
- `-l` 进入双栏 TUI，支持实时搜索、目录跳转、书签、代码/Markdown/PDF/压缩包预览。
- 自动提取目录 README 摘要，适合快速回忆项目用途。

## 安装

```bash
cargo install --path .
```

建议终端支持 24-bit color；图片预览会按环境自动选择合适方式，若没有图像协议则回退到系统默认程序。

## 常用命令

```bash
lsz
lsz path/to/dir
lsz -l [path]
lsz -i [path]
lsz -s "备注内容" path/to/file
lsz -d path/to/file
lsz -gc
lsz -b add work ~/code/work
lsz -b list
```

## TUI 操作

- `j` / `k` / `↑` / `↓`：移动选择
- `/`：进入类似 Vim 的实时搜索，输入即筛选，`Enter` 确认，`Esc` 退出
- `Enter`：进入目录或打开当前文件
- `←` / `Backspace`：返回上级目录
- `b`：把当前目录加入书签
- `B`：列出书签并跳转
- `e`：编辑当前文件备注
- `n`：代码全屏阅读时切换行号
- `q` / `Esc`：退出当前界面

## 预览策略

- Markdown / 代码：终端内直接预览或全屏阅读。
- PDF：优先文本提取后在终端阅读，失败时回退到系统默认程序。
- 压缩包：展示内部目录结构摘要。
- 图片：参考 Yazi 的思路优先适配终端环境；若当前环境缺少图像协议或适配器，则回退到外部查看器。

## 说明

- 备注与书签存储在 `~/.lsz.db`。
- 大目录采用按需分析：进入目录时先快速列出条目，详细预览信息只在选中项时懒加载，以减少卡顿。
