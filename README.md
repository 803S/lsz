# lsz

终端文件导航器，强调目录浏览、备注、书签和轻量预览。

## 功能

- 普通列表模式下按终端自己的颜色配置显示文件名，并在有备注时追加说明。
- `-l` 进入双栏 TUI：左侧文件列表，右侧预览。
- 支持备注、书签、README 摘要、压缩包摘要、图片/PDF 信息预览。
- 进入大目录时优先快速列出条目，详细分析只在选中项时懒加载。

## 安装

```bash
cargo install --path .
```

## 常用命令

```bash
lsz
lsz path/to/dir
lsz -l [path]
lsz -i [path]
lsz -s "备注内容" path/to/file
lsz -d path/to/file
lsz -gc
lsz -b add work ~/code/work
lsz -b list
```

## TUI 操作

- `j` / `k` / `↑` / `↓`：移动选择
- `/`：底部进入搜索输入，边输边筛选，`Enter` 确认，`Esc` 退出
- `Enter`：进入目录、打开文件或进入对应预览
- `←` / `Backspace`：返回上级目录
- `b`：收藏当前目录
- `B`：列出书签并跳转
- `e`：编辑当前文件备注
- `n`：代码阅读器切换行号；PDF/压缩包阅读器切换边框
- `q` / `Esc`：退出当前界面

## 预览策略

- Markdown / 文本：终端内直接预览或全屏阅读。
- 代码：全屏阅读时使用窗口切片渲染，优先保证稳定和大文件流畅度。
- PDF：优先终端文本阅读，失败后回退到系统默认程序。
- 压缩包：展示内部结构摘要。
- 图片：按终端环境选择可用适配器；不可用时回退到外部查看器。

## 数据位置

- 备注和书签保存在 `~/.lsz.db`。
